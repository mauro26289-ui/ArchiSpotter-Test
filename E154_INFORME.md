# E154 — Recuperación de fotos dentro de la pantalla

Se comprueba también la visibilidad horizontal de cada fotografía antes de reintentar descargarla. Los elementos totalmente fuera de la pantalla no generan una solicitud de recuperación. Se mantienen los límites verticales y el sistema de respaldo, así como los 110 monumentos, el almacenamiento, el mapa y el diseño.

Validaciones: casos de visibilidad horizontal y vertical; sintaxis de JavaScript; referencias locales; integridad ZIP.
